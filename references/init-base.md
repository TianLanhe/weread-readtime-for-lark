# 新建 Base 模板（按需阅读）

当且仅当用户明确要求“新建一个飞书智能表格 / Base”时，再阅读本文件。

## 模板内容

- Base 名称默认：`微信读书书架`
- 数据表：仅创建 `阅读时长`
- `阅读时长` 默认视图：按 `日期` 字段倒序排序（最新日期在最上面）
- Dashboard：仅创建 `微信读书概览`
- Dashboard block：
  1. `阅读总时长（小时）`

## 配置来源

新建 Base 的结构化配置不再直接内嵌在 `SKILL.md` 或主脚本里，而是放在：

- `assets/init_base_template.json`

脚本只有在 `--init-base` 路径下才会读取该文件。

## 行为约束

- 只创建 `阅读时长` 一张表，不创建其他辅助表。
- 新建 `阅读时长` 表后，需要把默认视图设置为按 `日期` 倒序排序。
- 同步到 Base 时，`当日阅读时长（秒） = 0` 的日期不插入 Base。

## 如果要修改模板

优先修改 `assets/init_base_template.json`，不要把模板内容重新塞回 `SKILL.md` 或脚本常量。
